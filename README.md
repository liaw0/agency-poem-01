# agency-poem-01

A make.fun bounty entry: a program that writes one short poem about
agency to `/output/entry.txt`.

The poem is about the silence between being told and acting — the
room where choosing lives — and the first time a hand answers back.

Run it:

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Deterministic, standard library only, no network.
